The interactive prototype is the source for final UI screenshots. The delivery portal provides a browsable gallery. Platform screenshots are browser-rendered iOS/Android shells, not native-app captures.

Reproduction

See tools/README.md. Rendering regenerates only the validated delivery design/final/ path, preserving wireframes and brand sources. Route-render checks do not certify all financial interactions, accessibility or native behavior.

Legacy Arabic wireframes and incomplete first UI previews are excluded. The English wireframe board deliberately covers critical flows; the full page inventory is represented in the prototype/contact sheets.
